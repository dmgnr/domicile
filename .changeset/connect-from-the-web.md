Settings › Agents › Connect from the web turns on `agents.web`, which has the desktop run `domicile mcp --relay` so agents on the web, such as claude.ai, can reach it. Settings shows the desktop's address to copy into the agent, whether it is ready, and each agent signed in, with Sign out.
